# gchp.team01
[프로그램 소개]
---
본 프로그램은 미연시를 플레이하며 당신의 연애 스타일을 분석할 수 있는 가상 연애 시뮬레이터입니다.
연애에서 가장 중요한 4가지 요소를 직접 선정해, 새로운 연애 스타일 지표를 만들었습니다.
테스트가 끝나면 개발자가 미리 정해둔 결과지를 보여주는 것이 아니라, 연애 스타일 결과에 따른 생성형 AI의 실시간 리포트를 제공해드립니다.

시중의 미연시 게임은 불특정 다수를 위한 설정이지만, 본 프로그램은 '중앙대 AI학과 학생의 CC'라는 설정이기에 높은 몰입감을 준다는 차별점을 지닙니다.
또한 AI가 당신의 답변을 종합적으로 분석하여, 개인 맞춤형 해설을 제공한다는 점에서 의의가 있습니다.
실제 연애 상황이라 생각하고 답변하여, 몰랐던 당신의 연애 유형을 발견해보세요.


[프로그램의 내부코드 설명]
---
### 전체 실행 구조
`main.py`는 사용자의 선택을 입력받아 네 가지 연애 성향 지표의 점수를 계산하고, 최종적으로 4글자의 연애 스타일 코드를 생성합니다. main에서 생성된 코드는 `get_result_module.py`를 거쳐 `explain_module.py`로 전달되며, 생성형 AI가 작성한 맞춤형 결과의 유효성을 `result_validator.py`를 통해 검사한 후, 이를 통과하면 리포트가 최종 출력됩니다. 기능을 메인 실행 코드와 AI 결과 생성 코드, 처리 과정 중 오류 처리용 코드, AI 답변 유효성 검사 코드로 분리하여, 시나리오 진행 방식이나 AI 요청 방식을 수정하더라도 다른 부분에 미치는 영향을 줄였습니다.

### AI 결과 생성과 구현 난도
`explain_module.py`는 OpenRouter API에 연애 스타일 코드를 전달하고, 생성형 AI가 정해진 형식의 한국어 리포트를 작성하도록 요청하는 모듈입니다. 단순히 API에 문장을 보내는 것뿐 아니라 다음 기능을 포함합니다.

- 입력된 코드가 실제로 존재할 수 있는 4글자 조합인지 검사합니다.
- 각 글자의 의미와 가능한 16가지 유형을 AI에게 전달하여 결과의 정확성을 높입니다.
- 한 줄 요약, 전체 설명, 장점, 주의점, 잘 맞는 상대가 포함되도록 프롬프트를 구성합니다.
- 응답 상태 코드와 응답 데이터 구조를 확인하고, 상황에 맞는 오류를 발생시킵니다.

외부 AI 서비스는 인터넷 연결, API 키, 요청 제한, 서버 응답 형식 등 프로그램 외부 요인의 영향을 받습니다. 따라서 정상적인 결과를 생성하는 기능뿐 아니라 여러 실패 상황을 구분하고 처리하는 작업이 필요했다는 점에서 구현 난도가 높았습니다.

### 실행의 안전성과 오류 처리
`get_result_module.py`는 AI 결과 생성 과정에서 발생하는 예외를 처리하는 안전장치입니다. API 호출 중 오류가 발생해도 프로그램이 즉시 종료되지 않고, 사용자에게 오류 내용을 보여준 뒤 다시 시도할지 선택할 수 있도록 반복 구조를 적용했습니다.

- 인터넷 관련 오류를 구분하여 안내하고, 일정 시간 후 재시도할 수 있도록 합니다.
- 잘못된 API 키, 요청 제한, 잘못된 결과 코드, 예상하지 못한 API 응답 등의 오류를 사용자에게 전달합니다.
- 재시도 여부에는 `y` 또는 `n`만 입력할 수 있도록 검사합니다.
- 사용자가 재시도를 선택하면 결과 생성을 다시 실행하고, 종료를 선택한 경우에만 프로그램을 종료합니다.

또한 `main.py`의 선택지 입력 함수는 숫자가 아닌 값이나 1, 2 이외의 숫자가 입력되어도 종료되지 않고 올바른 값을 다시 입력받습니다. 이를 통해 사용자 입력 실수와 외부 API 오류가 발생하더라도 가능한 범위에서 실행을 유지하도록 설계했습니다.

### 테스트 및 검증 코드
`for_test.py`는 시나리오 전체를 진행하지 않고도 특정 연애 스타일 코드로 AI 결과 생성 기능을 독립적으로 시험하기 위한 코드입니다. `result_validator.py`는 생성된 결과에 필수 항목이 포함되었는지, 유효한 추천 유형이 존재하는지, 오류 메시지와 유사한 응답은 아닌지 검사합니다. AI 응답이 검증을 통과하지 못하면 최대 3회까지 자동으로 다시 생성하며, 계속 실패한 경우에는 기존 오류 처리 흐름에 따라 사용자에게 재시도 여부를 묻습니다.

[실행 방법]
---
Python 3.9 이상이 설치된 Windows, macOS, Linux에서 실행할 수 있습니다. 터미널을 열고 프로젝트 폴더로 이동한 뒤 운영체제에 맞는 명령을 실행해 주세요.

### 1. 필요한 패키지 설치

Windows PowerShell:
```powershell
py -m pip install -r requirements.txt
```

macOS 및 Linux:
```bash
python3 -m pip install -r requirements.txt
```

### 2. OpenRouter API 키 설정

Windows PowerShell:
```powershell
$env:OPENROUTER_API_KEY="발급받은_API_키"
```

macOS 및 Linux의 bash 또는 zsh:
```bash
export OPENROUTER_API_KEY="발급받은_API_키"
```

환경변수는 해당 터미널 세션에만 적용됩니다. API 키를 설정한 터미널에서 프로그램을 실행해야 합니다.

### 3. 프로그램 실행

Windows PowerShell:
```powershell
py main.py
```

macOS 및 Linux:
```bash
python3 main.py
```
