[프로그램 목적]
---
본 프로그램은 미연시를 플레이하며 당신의 연애 스타일을 분석할 수 있는 가상 연애 시뮬레이터입니다.
실제 연애 상황이라 생각하고 답변하여, 몰랐던 당신의 연애 유형을 발견해보세요.

[진행 방법]
---
1. 시뮬레이션이 시작되면, 연애 상황이나 질문 제시
2. 두 가지 행동 선택지 중 하나 선택
3. 모든 선택을 마치면, 선택들을 기반으로 연애 유형이 결정됨
4. AI가 실시간 분석 진행하여, 종합적 연애 성향이나 잘맞는 유형 말해줌

[실행 예시]
---

2: 인스타 염탐을 하다 걸려서 그냥 팔로우를 건다
