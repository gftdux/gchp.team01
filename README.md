# gchp.team01
[프로그램 소개]
본 프로그램은 미연시를 통해 당신의 연애 스타일을 분석하는 가상 연애 시뮬레이션입니다. 실제 연애 상황이라 생각하고 답변하여, 당신도 몰랐던 연애 유형을 발견해보세요.

[진행 방법]
1. 시뮬레이션이 시작되면 연애 상황이나 질문이 제시됩니다.
2. 각 상황마다 주어지는 두 가지 행동 선택지 중, 더 끌리는 행동을 선택해주세요.
3. 모든 선택을 마치면 선택들을 기반으로 당신의 연애 유형이 결정됩니다.
4. 연애 유형이 정해지면, AI가 실시간 분석을 진행하여 당신의 종합적 연애 성향이나 잘맞는 유형 등을 말해줍니다.
