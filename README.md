# gchp.team01
[프로그램 소개] 왜 창의적인지
---
본 프로그램은 미연시를 플레이하며 당신의 연애 스타일을 분석할 수 있는 가상 연애 시뮬레이터입니다.
실제 연애 상황이라 생각하고 답변하여, 몰랐던 당신의 연애 유형을 발견해보세요.

[프로그램의 내부코드 설명] 구현난도(왜 구현하기 어려운지)와 실행의 안전성(오류처리 잘 되어있는지 오류가 발생해도 시스템 꺼지면 안됨) 어필
---
테스트 위한 코드와 안전성을 높이기 위한 코드

하고 여기엔 코드에 대한 설명을 써야할듯 - 코드 복잡성 알려주기 위해서
어떤 코드를 어떤 의도로 썼는지
형택이나 쓴 오류 방지에 대한 코드 같은 건 안 쓰면 모를 수 있으니까
이건 코드가 좀 완성 되면 쓰기 !

[실행 방법]
---
TERMINAL을 열고 해당 프로그램 파일을 실행해 주세요.
TERMINAL 화면에 연애 상황과 두 가지 행동 선택지가 출력되면, 번호를 입력 후 Enter 키를 누르시면 됩니다.
테스트가 끝나면 TERMINAL에 곧바로 '당신의 연애 스타일'과 AI가 분석한 '심층 결과 리포트'가 출력됩니다.

[진행 과정]
---
1. 시뮬레이션이 시작되면, 연애 상황이나 질문이 제시됨
2. 두 가지 행동 선택지 중 원하는 선택지의 번호 입력 (1 또는 2)
3. 모든 선택을 마치면, 선택들을 기반으로 연애 유형이 결정됨
4. AI가 실시간 분석 진행하여, 종합적 연애 성향이나 잘맞는 유형 말해줌

[실행 예시]
---
반짝이는 눈동자, 귀여운 목소리, 그리고 항상 밝은 웃음을 띄고 있는 그녀,
그녀를 보기만 해도 마음이 설레고, 가슴이 쿵쾅거리는 것을 느꼈다.

그래서 그날, 나는 용기를 내어 그녀에게 다가가기로 한다.

▶ 1: 무작정 다가가 말을 건다
